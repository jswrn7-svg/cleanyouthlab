청춘클린랩 현장관리 CRM v2 - 고객 공유 데모

설치: GitHub 새 공개 저장소 fieldcrm 생성 → ZIP 압축 해제한 파일 전체 업로드 → Settings > Pages > Deploy from branch > main /root.
기존 cleanquote 저장소에 덮어쓰지 마세요.

사용: 고객 등록 → 현장 등록 → 작업일지 작성 → 고객 공유 메뉴 → 고객 링크 만들기.
링크 복사/갤럭시 공유/고객 화면 미리보기를 지원합니다.
설정 > 고객 요청 수신 이메일을 입력하면 고객 페이지에서 메일 앱을 열어 요청사항을 보낼 수 있습니다.

중요: 이 버전은 정적 공유 스냅샷입니다. 실시간 동기화, 고객 로그인, 비공개 접근 제어, 서버 저장, 고객 요청 자동 수신은 없습니다.
링크에 현장명, 주소, 일정, 작업일지 텍스트가 포함되므로 민감한 정보는 입력하거나 공유하지 마세요.
고객 화면에는 현장 사진, 금액, 직원 연락처, 고객 연락처를 넣지 않습니다.
실제 고객에게 안전하게 제공하려면 인증과 클라우드 DB가 있는 서버 버전이 필요합니다.
